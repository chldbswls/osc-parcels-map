# 1시간차 데모 — 필지 데이터

출처: **『OSC(Off-Site Construction)기반 매입임대주택 정비모델 연구』** (LH 토지주택연구원, 연구관리 2025-026, 이지은 외)
파일: `[LH 연구]OSC기반 매입임대주택 모델 연구/OSC(...)정비모델 연구 - 3.pdf` (본문 213p + 부록)

## 이 리스트가 뭔지

이 연구는 **서울시 LH 매입임대주택(다가구·다세대 등 非아파트) 중 준공 20년 이상 노후 필지**를,
OSC(모듈러) 공법으로 철거 후 재건축·정비하는 모델을 제안한다. 그 과정에서
GIS(브이월드·연속수치지형도)로 각 필지의 물리 여건을 분석하고, OSC 공법 유형(소형/중형/대형 패널)과
신규 임대유형(청년·신혼부부 등)을 배정했다.

부록에 **클러스터(생활권)별 노후 매입임대 필지 목록**이 표로 실려 있고, 두 종류다:

| 표 | 키 | 컬럼 |
|---|---|---|
| 현황표(지형·도로) | 매입임대 고유번호 + 지번 | 지형높이, 지형형상, 도로접면, **사업방향(OSC 공법유형)** |
| 건축표(면적·율) | 매입임대 고유번호 + 지번 | 노후년수, 임대세대수, 대지면적, 건폐율, 용적률, 주택형태 |

두 표의 고유번호는 서로 다르게 매겨져 있어 **(자치구·법정동·지번)으로 조인**했다.

## 데모에서 쓰는 법

1. 학생이 이 목록에서 필지 하나를 고른다(예: `관악구 신림동 1573-28`).
2. "AI가 기억만으로 쓴 대지 소개서" (틀린 값) 를 먼저 보여준다.
3. 같은 필지를 **VWorld + 토지이음 API**로 조회 → 정확한 값(용도지역·면적·건폐/용적 상한)으로 대조.
4. 이 CSV의 값(지형·도로접면·노후·세대수)은 "LH 연구가 이미 조사한 결과" 로서 3번 조회값과 교차 확인.
